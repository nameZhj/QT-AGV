# 2026-06-26

## MQTT TransportInvalid 修复

### 问题
`QMqttClient` 报 `TransportInvalid` 错误，MQTT 无法连接。

### 根因分析（通过阅读 Qt 6.11.0 MQTT 源码 `F:/Qt/qtmqtt/src/mqtt/`）

1. **`MqttService::connectToHost()` 缺少状态守卫**
   - `QMqttClient` 的所有 setter（`setHostname`/`setPort`/`setUsername` 等）在 `state != Disconnected` 时**静默返回**，不设置任何值（见 `qmqttclient.cpp` 第 857、873、889 等行）
   - `QMqttClient::connectToHost()` 在 `state == Connecting` 或 `Connected` 时也直接 return
   - 当多个 widget（AgvInfoWidget、MapViewWidget、CreateMapWidget）在 client 处于 `Connecting` 状态时调用 `connectToHost()`，所有 setter 静默失败，hostname/port 可能未更新

2. **`onMqttStatusClicked()` 中 `disconnectFromHost()` + `connectToHost()` 背靠背调用**
   - 当 client 处于 `Connecting` 状态时，`disconnectFromHost()` 调用 `m_transport->close()`
   - `close()` 同步触发 `aboutToClose` 信号 → `transportConnectionClosed()`
   - `transportConnectionClosed()` 检查 `m_internalState`：此时是 `BrokerConnecting`（不是 `BrokerDisconnected`），于是 emit `TransportInvalid`
   - 这就是用户看到的 `TransportInvalid` 错误的直接来源

### 修改的文件
- `src/core/MqttService.cpp`：
  - `connectToHost()` 增加状态守卫：非 `Disconnected` 状态先 `disconnectFromHost()`（同步将 state 置为 Disconnected），再设置参数
  - `host.trimmed()` 去除 IP 地址可能的前后空格
  - 添加 `#include <QDateTime>`
  - `onErrorChanged()` 改为输出可读错误名 + client state + hostname + port
- `src/core/MainWindow.cpp`：
  - `onMqttStatusClicked()` 移除 `disconnectFromHost()` 调用，直接 `connectServices()`

### 第二次修复：系统代理导致 TransportInvalid

#### 问题
第一次修复后 hostname/port 已正确设置（192.168.31.110:1883），但仍报 `TransportInvalid`，state 为 `Connecting`。

#### 根因
阅读 Qt 源码 `qmqttconnection.cpp` 第 240 行：`ensureTransport()` 创建 `QTcpSocket`；第 278 行：`socket->connectToHost()` 发起异步 TCP 连接。`QTcpSocket` 继承 `QAbstractSocket`，默认使用 `QNetworkProxy::applicationProxy()`（系统代理）。用户系统开着代理/VPN 时，原始 MQTT TCP 流量被路由到 HTTP/SOCKS 代理，代理无法处理导致 socket `errorOccurred` → `transportError()` → `closeConnection(TransportInvalid)`。MQTTX（Electron）不走系统代理所以正常。

#### 修复
`main.cpp` 中 `QApplication` 创建后立即调用：
```cpp
QNetworkProxy::setApplicationProxy(QNetworkProxy::NoProxy);
```
全局禁用代理。本应用是局域网 AGV 客户端，所有连接（MQTT/WebSocket/HTTP API）都指向局域网服务器，禁用代理是正确做法。
